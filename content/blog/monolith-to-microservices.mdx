## Why we started

The monolith was old enough to have opinions. Deployments took long, one bad merge took everyone down, and downtime was measured in interesting units.

## What we did

- Strangled features out one by one, behind feature flags
- GitHub Actions + Docker pipelines, small and boring on purpose
- REST where it's simple, GraphQL where clients kept asking for "just one more field"

## What I'd do differently

More telemetry earlier. You can't see what you broke if you never watched it work.
